# Alex Harper — refonte du site

Site vitrine responsive en HTML, CSS et JavaScript vanilla. Aucun framework ni build requis.

## Lancer en local
Ouvrir `index.html` dans un navigateur. Pour un aperçu plus fiable, lancer un serveur local :
- Python : `python -m http.server 8000`
- Puis ouvrir `http://localhost:8000`

## Avant mise en production
1. **Vérifier les liens de diffusion** : les liens Spotify, Apple Music, Deezer, YouTube Music et DistroKid sont des destinations génériques de démonstration à remplacer par les liens officiels d'Alex.
2. **Ajouter les fichiers audio** : les titres indiqués « Extrait à venir » sont des emplacements prévus pour les extraits réels. Le clic affiche actuellement une note descriptive.
3. **Vérifier l'adresse e-mail** : le formulaire ouvre le logiciel e-mail du visiteur via `mailto:bonjour@alexharper.fr`. Remplacer cette adresse si nécessaire. Pour un formulaire qui envoie directement les messages, connecter un service ou un backend.
4. **Valider les images** : les photos de fond viennent d'Unsplash à titre de direction artistique. Remplacer par des photos autorisées et cohérentes avec l'identité d'Alex Harper.
5. **Paiement** : le CTA de chanson personnalisée mène au formulaire de contact. Le paiement en ligne n'est pas configuré, car aucun prestataire ni lien de commande existant n'a été fourni.
6. **Pages légales** : ajouter les mentions légales, la politique de confidentialité et les conditions de vente applicables.

## Contenu repris
Le positionnement éditorial et les offres affichées s'inspirent des informations visibles sur alexharper.fr : chansons françaises intimes, album *Ce que je n'ai jamais dit*, chanson personnalisée à 29,99 €, et présence de l'artiste à Bruxelles. Le design et le code sont reconstruits pour cette proposition.
